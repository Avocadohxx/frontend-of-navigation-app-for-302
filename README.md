# Campus Navigation

This is a very useful tool for students of Shanghai Ocean University. It includes everything you need in your daily life, including campus map navigation to help you not get lost on campus. It also includes a class schedule system to let you know when and where to have classes. Additionally, it includes a classroom reservation system, which you can use to book available classrooms for activities and communication.

这是一个对于上海海洋大学学生来说非常有用的工具，它包含了你的所有日常所需，包括校园地图导航，让你不会在校园里面迷路。也包含了课程表系统，让你知道什么时候，在什么地方上课。还包含了教室预定系统，你可以使用它预约空闲的教室，进行活动和交流。
